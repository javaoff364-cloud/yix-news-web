04 · AUTHENTICATION

API key bilan ishlash

Ochiq /api/site-news uchun key shart emas. Himoyalangan /api/news va /api/me uchun API key kerak.

  1. API Dashboardga o‘ting.
  2. Telegram orqali login qiling.
  3. Berilgan API key’ni xavfsiz saqlang.
  4. Key’ni server tomonda Authorization header orqali yuboring.
HTTP header 
Authorization: Bearer YIX_YOUR_API_KEY
API key’ni frontend kodiga, ochiq GitHub repository yoki ommaviy joyga joylamang.

06 · MODEL CONTEXT PROTOCOL

AI agentlar uchun MCP

MCP server AI klientlarga YIX News ma’lumotlarini tool sifatida chaqirish imkonini beradi. Transport turi — Streamable HTTP.

MCP URLhttps://yixnews-mcp.vercel.app/api/mcp
  1. MCP qo‘llaydigan klientda remote server qo‘shing.
  2. Transport sifatida Streamable HTTP ni tanlang.
  3. Yuqoridagi endpoint URL’ni kiriting.
  4. Tool’larni yangilang va get_news ni chaqiring.
Bu remote HTTP MCP server. Uni local stdio server sifatida sozlamang. Klientning ulash oynasi farq qilishi mumkin.
