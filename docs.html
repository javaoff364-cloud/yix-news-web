YIX News API

YIX News API orqali YIX News platformasidagi yangiliklardan dasturlaringizda foydalanishingiz mumkin.

Base URL

https://yix-news.onrender.com

Authentication

API ishlatish uchun Telegram orqali login qilib, API key olishingiz kerak.

Authorization: Bearer YIX_YOUR_API_KEY

GET /api/news

Yangiliklarni olish.

GET /api/news?limit=30&offset=0

Kategoriya

GET /api/news?category=technology

Mavjud kategoriyalar:

  • uzbekistan
  • world
  • technology
  • economy
  • science
  • sport
  • cinema

Pagination

GET /api/news?limit=50&offset=50

Bir requestda maksimal 100 ta yangilik olinadi.

Response

{
  "success": true,
  "count": 30,
  "limit": 30,
  "offset": 0,
  "news": [
    {
      "title": "News title",
      "summary": "News summary",
      "source": "BBC",
      "url": "https://example.com",
      "image": "https://example.com/image.jpg"
    }
  ]
}

Rate Limit

🆓 Free API

1,000 requests / day

Limit har kuni avtomatik yangilanadi.

Errors

401 — API key required

429 — Daily API limit reached

500 — Server error
